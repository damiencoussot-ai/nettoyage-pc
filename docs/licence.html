2. CE QUE FAIT LE LOGICIEL

Nettoyage PC nettoie, optimise et surveille un ordinateur sous Windows 10 ou Windows 11 : suppression de fichiers temporaires et de caches, optimisation des disques, bilans de sécurité, mises à jour, sauvegarde, outils de diagnostic.

Les engagements de l'Éditeur sur le fonctionnement du logiciel :

  • vos documents, photos et vidéos ne sont jamais supprimés par les nettoyages ;
  • un point de restauration de Windows est créé avant les opérations importantes, et les modifications de réglages peuvent être annulées depuis l'onglet Historique ;
  • le logiciel ne désactive jamais l'antivirus, le pare-feu ni Windows Update ;
  • chaque action qui touche tout le PC demande votre confirmation et l'autorisation de Windows ;
  • un « mode simulation » permet de voir ce qu'une action ferait, sans rien modifier.

Comme tout logiciel qui agit sur le système, Nettoyage PC doit être utilisé avec attention : lisez les messages de confirmation, et gardez une sauvegarde de vos fichiers importants (l'onglet Protéger > Sauvegarde vous y aide).
